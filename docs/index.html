Inlay renders images, surfaces, charts, and animations where you inspect them: in IRB, Pry, Jupyter, or a supported terminal.

Get started ↗Compatibility notes
$ gem install inlay
One small adapter

Fits the way you already work

Install the optional adapter for your environment. Inlay keeps notebook and terminal integrations opt-in, so a basic install stays small.

01 / REPL

IRB & Pry

Return an image at the prompt and see it inline, with a short summary ready for the next command.

02 / NOTEBOOK

IRuby & Jupyter

Display PNG images, SVG or PNG charts, and animated GIF output with a first-frame fallback.

03 / TERMINAL

Kitty, iTerm2 & Sixel

Choose the terminal protocol through Termvas, with true-color blocks as a portable fallback.
